## Overview & Architecture

Proprietary developer assistants (e.g. GitHub Copilot, ChatGPT CLI) require paid subscriptions, mandatory user accounts, and continuously transmit your source code, filenames, and terminal logs to third-party cloud servers.

The **`ai`** command replaces cloud dependencies with **100% localhost execution**:
- **0 Telemetry & 0 Data Leakage:** Every token is generated by your local model (such as Llama 3.2 3B or Qwen 2.5 3B/7B) running on your own CPU/GPU via `llama-server`.
- **Zero Configuration:** Works out of the box with standard `curl` and Python standard library—no heavy Python dependencies, node packages, or virtualenvs required.
- **Injection-Safe Input Handling:** Context, questions, and piped code are passed safely via environment variables and quoted heredocs, preventing shell breakout or code execution bugs when reviewing external files.
- **Instant Response:** Leverages your GPU offloading (`-ngl 99`) for fast completions.

## Prerequisites

Before using the `ai` command, ensure your local `llama-server` is active:

```bash
# Start your local llama-server:
run-llama-server
```

*(Or ensure the `llama-server.service` systemd service is active as documented in [USAGE-LLAMA-CPP.md](../../Setup-LLAMA-CPP/USAGE-LLAMA-CPP.md)).*

Verify connectivity:
```bash
curl -s http://127.0.0.1:8080/health
```

## Basic Terminal Q&A

Ask programming, Linux administration, or algorithms questions directly from your terminal:

```bash
# General developer questions
ai "What is the difference between hard links and soft links in Linux?"

# Syntax reminders
ai "Show me the syntax for a bash while loop reading a file line-by-line"

# Quick algorithms
ai "Write a Python function to check if a binary tree is balanced"
```

## Generating Executable Shell Commands (`-c`)

Use the `-c` (or `--cmd`) flag when you need a single, precise bash command without any markdown explanations or conversational filler.

```bash
# Find files modified in the last 24 hours
ai -c "find all files modified in the last 24 hours in current dir"

# Extract audio from an mp4 file
ai -c "extract audio from input.mp4 to output.mp3 using ffmpeg"

# Check open listening ports
ai -c "list all open listening TCP ports with their process IDs"

# Direct execution (Power User):
eval $(ai -c "find files larger than 100MB in home directory")
```

## Piping Files & Logs (Stdin Workflows)

The `ai` tool automatically detects piped standard input and sends the context along with your prompt to your local model.

### 1. Debugging Build Errors & Logs

```bash
# Explain kernel hardware warnings
dmesg | tail -n 40 | ai "Analyze these kernel messages for hardware failures"

# Explain compilation error
gcc -Wall main.c 2>&1 | ai "Why is this C code failing to compile?"

# Inspect Nginx error logs
tail -n 30 /var/log/nginx/error.log | ai "Explain what is causing these HTTP 500 errors"
```

---

### 2. Writing Git Commit Messages

Generate concise, conventional commit messages directly from your staged Git changes:

```bash
git diff --staged | ai "Write a conventional commit message (type: summary) for these changes"
```

Or automate committing:
```bash
git commit -m "$(git diff --staged | ai -c 'write a 1-line conventional commit summary')"
```

---

### 3. Code Review & Refactoring

```bash
# Review a script for security or performance issues
cat script.py | ai "Find potential security vulnerabilities and performance bottlenecks"

# Translate code between languages
cat utils.py | ai "Convert this Python function into modern C++20"
```

---

### 4. Explaining System Information & Network Data

```bash
# Explain routing table
ip route | ai "Explain this network routing configuration simply"

# Explain memory breakdown
free -h | ai "Explain my current RAM and swap usage"
```

## Geany Code Editor Integration

You can trigger your local AI copilot directly inside **Geany** without leaving your editor:

1. Open **Geany**.
2. Go to **Build** -> **Set Build Commands**.
3. Under the **Execute Commands** section, click an empty entry:
   - **Label:** `AI Code Review`
   - **Command:** `bash -c 'cat "%f" | ai "Review this file for bugs and optimizations:"'`
4. Under **Keyboard Shortcuts** (Edit -> Preferences -> Keybindings), assign a shortcut like <kbd>F9</kbd> or <kbd>Ctrl+Alt+A</kbd> to `Execute Command 1`.
5. Now, pressing your shortcut immediately reviews the currently open file with your local model!

## Configuration & Environment Variables

You can customize the endpoint and timeouts in your `~/.bashrc`:

```bash
# If your llama-server is running on a different port or machine:
export LLAMA_SERVER_URL="http://127.0.0.1:8080/v1/chat/completions"

# Increase timeout for complex reasoning tasks (default: 60 seconds):
export AI_TIMEOUT="120"
```
